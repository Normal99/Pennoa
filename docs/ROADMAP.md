# Roadmap

Each phase ends with measurable exit criteria. Phases 5–8 can overlap once Phase 4 is done.
**Test hardware:** a single ThinkPad X1 Yoga running Hyprland (KDE Plasma for screen-reader tests). Other devices come later, through community testers.
**Distribution until 1.0:** GitHub releases, Flathub and the AUR. **No app stores yet** (licence groundwork is in place, ADR-0011).

| Phase | Delivers | Exit criteria |
|---|---|---|
| **0 · Spikes** | (1) **Day-one hardware check** of the X1 Yoga (see RESEARCH §12). (2) Slint 1.19 winit backend + custom application handler + own `zwp_tablet_v2` listener + wgpu wet-ink layer, on Hyprland; tearing-control vs FIFO latency comparison. (3) vello tile renderer. (4) **Recognition benchmark**: every candidate model on 20–30 pages of the maintainer's Norwegian and English notes, text + math/physics. (5) Giac `cxx` shim "hello solve". (6) NB-Whisper transcription test on a recorded lesson | Pressure, tilt and eraser received; pen-to-pixel ≤ 20 ms p95 measured with presentation feedback; Orca reads the Slint UI on Plasma; benchmark report (CER, expression accuracy, latency per model); ADR-0001 confirmed or fallback chosen |
| **1 · Notebook core** | Workspace crates; Fluent i18n with English + Norwegian (nb, nn); library/subject/notebook/page model; pen, highlighter, eraser, lasso, undo/redo; paper sizes + infinite canvas; **templates** (lined, squared, dotted, Cornell, graph, music, periodic table, user templates); Automerge file format **+ `docs/FORMAT.md` spec**; FTS search; Home, Editor and Settings screens; **accessibility baseline** (keyboard navigation, focus ring, high contrast, left-handed mode, reduced motion) | 500-page notebook opens < 300 ms; no dropped frames while inking; fuzzed page parser; crash-free 2-hour writing session; every screen usable by keyboard only |
| **2 · Sync & backup** | `Remote` trait over OpenDAL (local folder, WebDAV, Google Drive, OneDrive, SFTP, S3); merge-based sync; snapshots; age E2E; keyring (+ encrypted-file fallback on Hyprland) | Concurrent edits on two devices merge without loss (property test); restore of any snapshot; zero plaintext on remote with E2E on |

## Project housekeeping
- **Done:** LICENSE + §7 permissions, CONTRIBUTING (DCO), SECURITY, CODE_OF_CONDUCT, issue/PR templates.
- **When code starts (Phase 0):** CI (build, clippy, tests, `cargo deny`), GitHub milestones per phase.
- **Later:** app icon and branding; funding page (GitHub Sponsors / Open Collective) when there are real costs, e.g. Google OAuth verification, an Apple developer account, a legal entity for Microsoft publisher verification.

## Open questions
1. **Hardware for Tier B personalisation:** check on arrival whether the X1 Yoga has only an iGPU (likely), which decides on-device LoRA.
2. **Google Drive OAuth client:** the project needs its own Google Cloud OAuth client, which requires Google verification for the Drive scope.
3. **IME under Flatpak:** can Hyprland's `exec-once` / KWin launch a Flatpak-ed input method that binds input-method-v2/v1, or is a host package (e.g. AUR) needed?
4. **Legal entity:** needed only for Microsoft publisher verification (OneNote/Teams sign-in in schools) and, much later, app stores.
5. **Licence review:** have `LICENSE-ADDITIONAL-PERMISSIONS.md` reviewed (lawyer or FSF/FSFE) before any app-store release.
6. **InSchool:** check the student web menu for any calendar or ICS export before building the experimental connector.

**Resolved:** the project name is **Pennoa** (from *penn*, Norwegian for pen). "Skisse" (Norwegian for sketch) is reserved for a future signature feature, chosen by the maintainer.
