# Contributing to StudyInk

Thank you for helping. Before you send a change, please read this section about licensing.

## Licence of contributions
StudyInk is licensed under **GPL-3.0-or-later with two additional permissions** (see `LICENSE-ADDITIONAL-PERMISSIONS.md`):
1. distribution through app stores such as Apple's;
2. use of Slint under its Royalty-free licence.

By submitting a contribution, you agree that it is licensed under these same terms, **including both additional permissions**. This keeps StudyInk distributable on every platform.

## Developer Certificate of Origin
Every commit must be signed off (`git commit -s`). This certifies the [Developer Certificate of Origin 1.1](https://developercertificate.org/): you wrote the change, or have the right to submit it under the licence above.

## Third-party code
Only add dependencies whose licences are on the allow-list in `deny.toml`. Never copy code from projects with incompatible licences: GPL-2.0-only, non-commercial or "source-available" licences.
