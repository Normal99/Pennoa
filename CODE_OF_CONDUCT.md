# Code of conduct

Pennoa follows the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.

In short:
- Be kind and patient.
- Assume good intent.
- Remember that many users and contributors are students, some of them under 18.
- Harassment, discrimination and personal attacks are not tolerated.

Report problems to the maintainers privately via GitHub (see `SECURITY.md` for the private channel). They will handle reports confidentially.
