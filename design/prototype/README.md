# UI prototype

Interactive canvas with 8 artboards (Home, Editor, Ask AI, Scanner, Learn and Focus, Export, Settings, Design system):
https://claude.ai/artifact/UCt8hMiVNutvARi4s4JVvR

`project/*.dc.html` are the artboard sources. `project/canvas.json` lays them out. Every artboard has a **dark** tweak, and the interactive ones can be played: tap the island, change tools, lasso → Calculate, start the focus timer, flip toggles.
The visual language is specified in [`docs/DESIGN-SYSTEM.md`](../../docs/DESIGN-SYSTEM.md).
